# 화면이 낡았을 때 자동으로 다시 찍기

> `asof`가 **"무엇이 낡았나"**를 알려준다. 이 문서는 그다음을 다룬다 — **"그럼 어떻게 다시 채우나."**

## 왜 이게 핵심인가

강의자료 한 건에 서비스 스크린샷이 스무 장, 서른 장 들어간다.
도구가 업데이트되면 그걸 다 다시 찍어야 한다. **그래서 안 고친다.**
낡은 걸 알면서도 그냥 쓴다 — 고치는 비용이 너무 크니까.

**`asof`는 "어디를 고칠지"를 알려주고, 이 문서는 "고치는 비용"을 없앤다. 둘이 짝이다.**

---

## 한 줄

> ## 찍은 그림을 보관하지 말고, **다시 찍을 수 있는 상태**를 보관한다.

| 무엇을 | 안 갖는다 | 대신 갖는다 |
|---|---|---|
| 책에서 뜯은 그림 | 크롭 PNG | **`figures_todo` + 원본** → [01-책-그림과-텍스트](01-책-그림과-텍스트.md) |
| 내가 만든 장표 | 장별 PNG | **HTML** — 스크립트가 다시 찍는다 |
| 서비스 화면 | 스크린샷 | **`shots.txt` + 캡처 스크립트** |

⇒ **갱신이 "다시 만들기"가 아니라 "다시 실행"이 된다.**

---

## 🔴 먼저 알아야 할 것 — **헤드리스는 봇 차단에 막힌다**

로그인이 필요 없는 페이지라도 그렇다. Cloudflare 뒤에 있는 사이트를
`chrome --headless --screenshot` 으로 뜨면 **봇 검증 페이지나 빈 화면**이 찍힌다.
**파일은 멀쩡히 생겨서 열어보기 전엔 모른다.**

| 실측 | 결과 |
|---|---|
| claude.ai 공유 링크 (2026-08-03) | 헤드리스 → **봇 검증 페이지만** 찍힘 |
| openai.com 요금제 (2026-08-24) | 헤드리스 → **로고만 있는 빈 PNG** |
| anthropic.com · notebooklm.google | 헤드리스도 **됨** (CF 게이트 없음) |
| **같은 openai.com 요금제를 `capture_live.py` 로** | ✅ **591KB · 1905×8706 풀페이지** — 요금표·비교표·FAQ 전부 |

> **같은 URL, 같은 날, 26KB vs 591KB.** 헤드리스냐 헤디드냐만 달랐다.

## 🟢 먼저 — 이걸 직접 돌릴 필요는 없다

이 문서는 **안이 어떻게 생겼는지**를 적은 것이다. 실제로 쓸 때는 **클로드 코드(또는 쓰는 AI)에게 시키면 된다.**
설치·옵션 이름·에러 처리는 그쪽 일이다. **기억할 것은 문장 넷이다.**

**준비 (한 번)** — 도구모음 zip을 작업 폴더에 풀고, 그 폴더에서 클로드 코드를 연다.

```
① 이 폴더 tools/ 에 capture_pages.py 와 shots.txt 가 있어.
   아래가 내 강의자료에 들어간 화면들이야. shots.txt 에 적고 한 번 돌려 줘.
   필요한 패키지가 있으면 설치하고, 결과를 요약해 줘.

   가입화면 = https://example.com/signup
   요금제  = https://example.com/pricing
```
```
② 방금 찍은 것 중에 빈 화면으로 의심된다고 나온 게 있으면
   capture_live.py 로 다시 찍어 줘. 그것만.
```
```
③ 캡처 목록에서 180일 넘은 게 있는지 확인해 줘.
   있으면 그것만 다시 찍고, 뭐가 바뀌었는지 알려 줘.
```
```
④ 다시 찍은 화면이 내 강의자료 어느 파일에 들어가 있는지 찾아 줘.
   바뀐 게 있으면 어디를 고쳐야 하는지 알려 주고, 파일은 아직 고치지 마.
```

> ④의 마지막 줄이 중요하다. **먼저 보여달라고 해야** 엉뚱한 자리를 고쳐 놓는 걸 막는다.

### AI에게 한 줄 알려줘야 하는 것

AI는 **헤드리스가 봇 차단에 막힌다는 걸 모른다.** 그래서 남의 사이트도 빠른 쪽으로만 돌리려 한다.

```
외부 사이트는 헤드리스로 찍으면 빈 화면이 나올 수 있어.
남의 사이트는 capture_live.py 를 써 줘 — 진짜 크롬을 띄우는 쪽이야.
그리고 tools/pw_profile/ 은 로그인 세션이라 커밋하지 마.
```

**아래부터는 그 문장들이 실제로 무엇을 시키는지다.** 안 읽어도 도구는 돌아간다.

## 도구 둘 — 고르는 법

| 대상 | 도구 | 왜 |
|---|---|---|
| **외부 서비스** (남의 사이트) | **`capture_live.py`** ← 기본 | Playwright + **진짜 크롬을 화면 있는 채로.** 봇 차단을 통과한다 |
| **내 로컬 파일·자체 서버** | `capture_pages.py` | 헤드리스가 더 빠르고 확실하다. 차단 주체가 없다 |

> 로그인 여부로 가르는 게 아니다 — **누구 것이냐**로 가른다.
> `capture_live.py` 는 로그인이 필요하면 `--login` 한 번으로 프로필을 만들어 이어 쓴다.

---

## 1. 내 로컬 파일·자체 서버 — `capture_pages.py`

**준비**: 크롬만 있으면 된다. (여백 트림·빈 화면 감지를 쓰려면 `pip install pillow`)

**① 찍을 것을 적는다** — `shots.txt`

```
내덱      = C:/work/deck/index.html
실습화면   = http://localhost:8000/step3.html
사내대시보드 = http://intra.example.com/dashboard
```

⚠️ **남의 사이트를 여기 적지 마라.** 봇 차단에 걸려 빈 PNG가 남는다 → 2번으로.

**② 찍는다**

```
python capture_pages.py
```

`shots/` 에 PNG가 떨어지고, `shots.manifest.json` 에 **언제 찍었는지**가 기록된다.

**③ 낡은 것을 찾는다** ← 이게 이 도구의 진짜 값어치

```
python capture_pages.py --stale 180
```

```
기준 180일 · 오늘 2026-08-24

    241일   가입화면   (마지막 촬영 2025-12-26)
    198일   요금제     (마지막 촬영 2026-02-07)

  낡음 2장 · 최신 12장
```

**④ 그것만 다시 찍는다**

```
python capture_pages.py --only 가입화면
```

### 알아둘 것

- **넉넉한 높이로 찍고 아래 여백을 잘라낸다**(`--tall`, 기본 6000). 전체 높이를 미리 몰라도 된다.
- **폭은 의도한 값이다** — 좌우는 트림하지 않는다. `--width` 기본 1920.
- 크롬 경로를 못 찾으면 환경변수 `CHROME_EXE` 에 넣는다.
- 렌더가 덜 된 채로 찍히면 `--wait 12000` 으로 늘린다.

## 2. 외부 서비스 — `capture_live.py` (기본 경로)

### 세 가지를 바꾼다

| 바꾸는 것 | 왜 |
|---|---|
| **진짜 크롬을 쓴다** (`channel="chrome"`) | 번들 크로미움은 더 잘 걸린다 |
| **화면 있는 채로 띄운다** (`headless=False`) | 헤드리스 자체가 신호가 된다 |
| **자동화 표식을 끈다** | `--disable-blink-features=AutomationControlled` + `ignore_default_args=["--enable-automation"]` |

### 쓰는 법

```
pip install playwright

python capture_live.py --login     # 창이 뜬다. 손으로 로그인하고 닫는다. 1회만.
python capture_live.py             # shots.live.txt 를 전부 찍는다
python capture_live.py --stale 180 # 낡은 것 보고
```

**로그인이 필요 없는 사이트는 `--login` 없이 바로 찍는다.** 필요한 경우에만 한 번 로그인하면
프로필이 `pw_profile/` 에 남아 다음부터 재사용된다.

> ⚠️ **빈 화면이 나오면 이쪽으로 옮겨라.** `capture_pages.py` 가 `⚠ 거의 빈 화면이다` 라고
> 경고하면 그건 봇 차단에 걸린 것이다. 그 줄을 `shots.live.txt` 로 옮기면 된다.

> 🔴 **`pw_profile/` 을 공개 저장소에 올리지 마라.** 로그인 세션이 들어 있다.
> `.gitignore` 에 넣어 두는 게 안전하다.

## 3. 재촬영이 되게 만드는 규약

도구보다 이게 중요하다. **원본을 자체 완결로 보관한다.**

- 캡처 대상이 내가 만든 것이면(덱·실습 화면·데모) **HTML·데이터·상태를 통째로** 한 폴더에 둔다.
- 로컬 서버로 띄우면 그대로 열린다.

```
python -m http.server 8000 --directory 원본화면
```

- **그 서버를 재촬영에도 쓰고 라이브 시연에도 쓴다.** 하나로 두 몫을 한다.
- 샷마다 **"무엇이 보이나 / 어느 장에 쓰나"**를 표로 관리하면, 나중에
  *"이 화면이 어디에 박혀 있더라"*를 안 찾아도 된다.

---

## 4. 시드와 잇기

시드의 `asof` 와 `shots.manifest.json` 의 `captured` 는 **같은 일을 한다** — 낡음을 드러낸다.

1. 시드를 만들 때 `figures_todo` 에 **무엇이 보여야 하는지**를 적는다(그림은 갖지 않는다).
2. 교안을 만들 때 그 목록을 `shots.txt` 로 옮긴다.
3. 반년 뒤 `--stale 180` 이 낡은 것을 지목한다.
4. `--only` 로 그것만 다시 찍는다. **5분.**

> 이 고리가 돌기 시작하면, 자료를 **실제로 고치게 된다.**
> 지금까지 안 고친 건 게을러서가 아니라 **비용 때문이었다.**
