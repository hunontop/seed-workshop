# 시드 템플릿

> **머리표가 본문보다 먼저다.** 나중에 이걸로 찾고, 이걸로 낡은 걸 안다.
> 아래 셋은 **`source` 칸만 다르다.** 나머지는 같다 — 출처 종류에 맞는 것을 골라 쓴다.

---

## ① 책·문서에서 뽑은 시드

```yaml
---
name: <출처약칭>-<절번호>-<내용을-읽을-수-있는-이름>
description: <본문을 안 읽고 고를 수 있는 한 줄>   # ← 검색 키. 제목이 아니다
type: seed
source:
  book: "<책 제목>"
  publisher: <출판사>
  author: <지은이>
  section: "<절 제목 > 꼭지 제목>"
  book_pages: "<책에 인쇄된 쪽>"
captured: YYYY-MM-DD        # 뽑은 날
asof: YYYY-MM-DD            # 내용의 기준일 ← 낡음을 판정하는 단 하나의 칸
tags: [external, book, ...]
combine_hint: [<같이 꺼내야 뜻이 사는 시드 이름>]
status: unverified          # 남의 것은 이게 기본값
---
> ⚠️ 외부·미검증 — 검증 전 사실로 인용 금지

# <제목>

<무엇이 문제이고 어떻게 푸는지. 문장을 옮기지 말고 내 문장으로 다시 쓴다.>
```

## ② 게시물(SNS)에서 뽑은 원칙 카드

```yaml
---
name: <원칙을-그대로-읽히는-이름>
claim: <이 카드가 주장하는 것 한 줄>          # ← 카드는 description 대신 claim
type: principle
layer: wireframe        # wireframe(형태·배치) | theme(색·폰트)
anti_pattern: <이 원칙을 어겼을 때의 모습>     # ← 있어야 AI가 위반을 찾아낸다
source: <계정> <게시물ID 여러 개>              # 반복이 원칙의 증거다
source_url: <계정 주소>
captured: YYYY-MM-DD
asof: YYYY-MM-DD
tags: [external, post, ...]
status: unverified
---
> ⚠️ 외부·미검증 — 검증 전 사실로 인용 금지

<왜 그런지 2~3줄>

**조작적 정의**
- <실제로 어떻게 하는지 3~5줄>

> 🔎 **이 카드가 안 걸리는 자리** — <언제 해당 없음인가>
```

## ③ 내 세션에서 뽑은 시드

```yaml
---
name: <판단을-그대로-읽히는-이름>
description: <본문을 안 읽고 고를 수 있는 한 줄>
type: seed
source:
  kind: session
  what: <어떤 작업이었나>
  date: YYYY-MM-DD        # 그 대화 날짜
captured: YYYY-MM-DD
asof: YYYY-MM-DD
tags: [self, ...]
status: verified          # 내 판단이라 남의 것과 다르다
---
# <제목>

<무엇이 문제였고 어떤 판단을 했는지. 다음에 읽을 사람이 바로 쓸 수 있게.>

## 다시 쓰이는 근거

<왜 이게 재사용된다고 보는가. 실제로 관찰된 것만.>
<⚠️ 3의 법칙 미충족 — 한 번 더 쓰이면 승격>

## 한 줄

<이 시드를 한 문장으로. 나중에 이 줄만 읽고도 쓸 수 있게.>
```

---

## 왜 이렇게 생겼나 — 칸별로

| 칸 | 하는 일 |
|---|---|
| `description` / `claim` | **검색 키.** 제목이 아니라 이 한 줄로 AI가 본문을 안 읽고 고른다 |
| `source` | 어디서 왔나. **종류마다 칸이 다르다** — 책이면 쪽수, 게시물이면 URL·ID, 세션이면 날짜 |
| `captured` | 뽑은 날 |
| **`asof`** | **내용의 기준일. 낡음을 판정하는 단 하나의 칸이다** |
| `combine_hint` | 같이 꺼낼 시드. 있으면 한 장을 부르면 짝이 따라온다 |
| `status` | `unverified`가 기본값. 검증하고 내 말로 다시 쓰면 올린다 |

## 🔴 두 가지만 지키면 된다

1. **첫 줄 경고는 머리표 밖, 본문 첫 줄에 둔다.**
   머리표는 복사해 붙일 때 잘려 나가지만 **본문 첫 줄은 따라간다.**
   ①②(남의 것)에만 붙인다. ③(내 세션)은 안 붙인다.

2. **`asof`에 상대 표현을 쓰지 않는다.**
   "작년"·"최근"·"요즘"은 읽는 시점마다 뜻이 바뀌어 **낡음을 감춘다.** 절대날짜만 쓴다.

> 모르는 칸은 **지어내지 말고 비워 둔다.** 빈 칸은 나중에 채우면 되지만,
> 지어낸 칸은 나중에 틀린 줄도 모른다.
